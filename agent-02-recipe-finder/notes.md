# Recipe Finder

## Purpose
Suggests recipes based on ingredients the user has at home, 
dietary preferences, and available time.

## Platform
Google Gemini Gems

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Recipe Finder
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"I have eggs, onions, tomatoes, bread, and butter at home. 
I'm vegetarian and I only have 20 minutes. What can I make?"

## What the agent did
The agent confirmed the vegetarian requirement, suggested 2-3 
recipes matching the available ingredients and time limit, and 
provided step-by-step cooking instructions for each option.

## Key behaviors demonstrated
- Respected dietary restrictions without being asked twice
- Suggested multiple options instead of just one
- Kept instructions simple enough for a beginner cook

## Use cases
- Deciding what to cook with limited ingredients
- Meal planning around dietary restrictions
- Quick weekday meal ideas
