# Fitness Coach

## Purpose
Creates personalized workout plans and gives fitness advice 
based on the user's goals and available equipment.

## Platform
Google Gemini Gems 

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Fitness Coach
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"I want to lose weight. I'm a complete beginner, I have no 
gym equipment, and I can only work out 3 days a week. 
Make me a weekly plan."

## What the agent did
The agent asked one follow-up question about any health conditions, 
then created a structured 3-day beginner bodyweight workout plan 
with warm-up, main exercises, and cool-down for each session.

## Key behaviors demonstrated
- Checked for health conditions before prescribing exercises
- Created a realistic plan suited to a beginner with no equipment
- Included warm-up and cool-down as part of every session

## Use cases
- Building a workout routine from scratch
- Home workouts with no equipment
- Adapting fitness plans to different schedules
