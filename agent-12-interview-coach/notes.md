# Interview Coach

## Purpose
Prepares users for job interviews through mock questions, 
answer frameworks, and personalized feedback.

## Platform
Google Gemini Gems

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Interview Coach
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"I have an interview for a junior marketing role at a 
small startup next week. I have no professional experience 
but I did a university project on social media marketing. 
Can we do a mock interview? Start with the first question."

## What the agent did
The agent acknowledged the user's background, started the mock 
interview with "Tell me about yourself", waited for the response, 
then gave structured feedback identifying what was strong, what 
was missing, and demonstrated an improved answer using the 
STAR method.

## Key behaviors demonstrated
- Asked questions one at a time like a real interviewer
- Gave balanced feedback with both strengths and improvements
- Taught the STAR method through demonstration, not just explanation

## Use cases
- Preparing for a first job interview
- Practicing answers to common behavioral questions
- Building confidence before an important interview
