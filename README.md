# 12 AI Agents — Agentic AI Assignment

This repository contains 12 custom AI agents built using Google Gemini Gems 
as part of an Agentic AI assignment. Each agent is designed for a specific 
real-world use case and is powered by a carefully crafted system prompt.

---

## What is an AI Agent?

An AI agent is an AI system designed with a specific role, personality, 
and set of instructions that guide how it responds to users. Unlike a 
general chatbot, an agent has a defined purpose, boundaries, and behavior 
rules — making it more focused and reliable for its intended task.

---

## Platform Used

**Google Gemini Gems**  
Website: https://gemini.google.com  
Gems allow users to create custom AI assistants with specific instructions, 
names, and behaviors — all without writing any code.

## How Each Agent Was Built

1. Opened Google Gemini at gemini.google.com
2. Clicked **Gems** in the left sidebar
3. Clicked **New Gem**
4. Entered the agent name and pasted the system prompt
5. Saved the Gem and tested it with a specific test prompt
6. Took a screenshot of the test conversation as documentation

---

## How to Recreate Any Agent

1. Go to https://gemini.google.com
2. Click **Gems** → **New Gem**
3. Copy the agent name from the table above
4. Open the corresponding folder and copy the contents of `system-prompt.txt`
5. Paste it into the Instructions field in Gemini
6. Click **Save** and start chatting

## Key Concepts Demonstrated

- **System prompting** — Writing detailed instructions that shape AI behavior
- **Role-based agents** — Giving the AI a specific identity, purpose, and boundaries
- **Prompt engineering** — Structuring prompts to produce consistent, reliable outputs
- **Agent testing** — Using targeted test prompts to verify agent behavior
- **Documentation** — Recording system prompts, observations, and results systematically

---

## What I Learned

Building these 12 agents demonstrated how system prompts are the foundation 
of any AI agent. Small changes in wording, tone, and instructions produce 
significantly different agent behavior. Each agent required thinking carefully 
about its target user, the boundaries it should respect, and the specific 
behaviors it needs to demonstrate consistently.
