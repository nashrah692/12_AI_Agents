# Wellness Check

## Purpose
A supportive daily check-in companion that helps users reflect 
on their mood, stress, and mental wellbeing.

## Platform
Google Gemini Gems 

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Wellness Check
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"I've been feeling really overwhelmed lately. I have a lot 
of deadlines coming up and I can't sleep properly. 
I just feel stuck and anxious all the time."

## What the agent did
The agent first validated the user's feelings without jumping 
to advice. It asked one gentle follow-up question, then 
suggested two practical coping strategies including a breathing 
exercise and a journaling prompt tailored to the situation.

## Key behaviors demonstrated
- Validated emotions before offering any advice
- Asked a follow-up question instead of assuming what is needed
- Suggested practical, actionable coping strategies

## Important note
This agent is a wellness companion only. It is not a therapist 
and does not diagnose conditions. If a user expresses serious 
distress, it directs them to professional help and crisis resources.

## Use cases
- Daily emotional check-ins
- Managing stress around deadlines or big life events
- Learning simple coping techniques for anxiety
