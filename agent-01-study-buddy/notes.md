# Study Buddy

## Purpose
A patient AI tutor that explains any academic topic step by step 
for students of all levels.

## Platform
Google Gemini Gems

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Study Buddy
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"Hi! I'm a 10th grade student and I completely don't understand 
photosynthesis. Can you explain it to me in simple terms and 
then give me a practice question?"

## What the agent did
The agent introduced itself warmly, explained photosynthesis using 
a simple analogy, broke the concept into easy steps, and ended by 
offering a practice question to test understanding.

## Key behaviors demonstrated
- Adapted language to a 10th grade level
- Used a real-world analogy to explain an abstract concept
- Offered a quiz unprompted, showing proactive teaching behavior

## Use cases
- Homework help
- Exam preparation
- Understanding difficult concepts in any subject
