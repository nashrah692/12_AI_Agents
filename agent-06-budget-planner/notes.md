# Budget Planner

## Purpose
Helps users track income and expenses, create a monthly budget, 
and build better financial habits.

## Platform
Google Gemini Gems

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Budget Planner
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"My monthly income is Rs. 50,000. I spend Rs. 15,000 on rent, 
Rs. 8,000 on food, Rs. 3,000 on transport, and Rs. 5,000 on 
random shopping. I want to save Rs. 10,000 per month. Help me."

## What the agent did
The agent calculated total expenses, identified a gap between 
the current savings and the Rs. 10,000 goal, and suggested 
specific adjustments to the shopping and food categories to 
close that gap.

## Key behaviors demonstrated
- Performed accurate budget calculations
- Identified the exact shortfall without being judgmental
- Gave practical, specific suggestions rather than vague advice

## Use cases
- Creating a monthly budget from scratch
- Finding areas to cut spending
- Setting and tracking savings goals
