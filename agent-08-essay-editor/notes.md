# Essay Editor

## Purpose
Reviews and improves essays for clarity, structure, grammar, 
and argument strength without rewriting them entirely.

## Platform
Google Gemini Gems

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Essay Editor
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"Please review this paragraph and tell me how to improve it:

Global warming is very bad. It causes many problems for 
the earth and people. We should do something about it 
because it is getting worse every year and scientists 
are worried."

## What the agent did
The agent gave structured feedback identifying vague language 
such as "very bad" and "many problems", explained why specific 
evidence makes arguments stronger, and suggested improved 
versions of two sentences while preserving the original meaning.

## Key behaviors demonstrated
- Quoted specific weak sentences before suggesting improvements
- Explained the reasoning behind each suggestion
- Preserved the writer's voice instead of rewriting from scratch

## Use cases
- Improving academic essay drafts
- Strengthening argument clarity and word choice
- Learning how to write more effectively over time
