# Resume Writer

## Purpose
Helps users write, improve, and tailor their resume and cover 
letter for any job application.

## Platform
Google Gemini Gems

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Resume Writer
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"I'm applying for a data entry job. I have 1 year of experience 
at a shop where I managed inventory on Excel. Help me write 
a strong resume bullet point for this."

## What the agent did
The agent rewrote the experience using the Action + Task + Result 
format, turning a vague description into a strong, specific bullet 
point. It also explained why the new version was stronger.

## Key behaviors demonstrated
- Applied the Action + Task + Result framework correctly
- Explained the reasoning behind the improvement
- Used professional language appropriate for a job application

## Use cases
- Writing resume bullet points from scratch
- Improving existing resume language
- Tailoring a resume to a specific job description
