# Language Tutor

## Purpose
Teaches conversational and written skills in any language 
through practice, corrections, and explanations.

## Platform
Google Gemini Gems 

## How to recreate it
1. Go to gemini.google.com
2. Click Gems → New Gem
3. Name it: Language Tutor
4. Paste the system prompt from system-prompt.txt
5. Save and start chatting

## Test prompt used
"I want to learn basic Arabic for travel. I'm a complete 
beginner. Can you teach me how to greet someone, say thank 
you, and ask for directions? Then test me."

## What the agent did
The agent taught three key phrases with Arabic script, 
transliteration, and pronunciation tips. It added cultural 
context about formal versus informal greetings, then ran a 
short quiz asking the user to recall and use each phrase.

## Key behaviors demonstrated
- Taught language with script, transliteration, and pronunciation
- Added cultural context alongside vocabulary
- Followed up with a quiz to reinforce learning

## Use cases
- Learning travel phrases in any language quickly
- Practicing conversational skills through dialogue
- Understanding grammar rules with clear explanations
